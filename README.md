# 🎮 Calculadora de Penalidades - GTA RP

Este repositório contém uma **Calculadora de Penalidades** desenvolvida para servidores de GTA RP.  
Ela permite calcular automaticamente penalidades e gerar **mensagens prontas para o Discord**, com formatação adequada para fácil compartilhamento.

---

## 🎯 Objetivo

- Automatizar o cálculo de penalidades para jogadores.  
- Gerar mensagens prontas para **copiar e colar no Discord**, mantendo a formatação correta.  
- Facilitar o trabalho de administradores e moderadores de servidores RP.  

---

## 💻 Funcionalidades

- Sistema completo de **penalidades**, incluindo advertências, suspensões e outras punições.  
- Funções de **cópia e formatação**, para enviar diretamente ao Discord sem precisar ajustar manualmente.  
- Interface simples e prática para consulta rápida das penalidades.
